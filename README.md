# GPS Journey — Angular + Node.js + Longdo Map

เว็บทดลองสำหรับปักหมุดปลายทางและบันทึกเส้นทางจริงจาก GPS ของมือถือ

## ห้องคนขับและผู้โดยสาร

- คนขับและผู้โดยสารเลือกบทบาทบนหน้าแรก แล้วใส่เลข ID ห้องเดียวกัน
- คนขับกด “เริ่มแชร์และบันทึก” เพื่อส่งตำแหน่งสด
- ผู้โดยสารจะเห็นตำแหน่งและเส้นทางของคนขับโดยอัตโนมัติ
- ทั้งสองฝ่ายแตะแผนที่เพื่อแชร์จุดหมายร่วมกันได้
- ระบบแสดงระยะเส้นตรงจากตำแหน่งรถถึงหมุดหมาย

## เริ่มใช้งาน

1. ติดตั้งและ build: `npm install` แล้ว `npm run build`
2. เปิดเซิร์ฟเวอร์: `npm run serve:prod`
3. เปิด `http://localhost:3000` (บนมือถือควรใช้ HTTPS ผ่าน tunnel)

Longdo Map API Key ตั้งค่าไว้ที่ `src/environments/environment.ts` ส่วนประวัติ 10 ทริปล่าสุดเก็บใน localStorage ของอุปกรณ์นั้น ข้อมูลสดแยกตามเลข ID ห้องผ่าน SSE และสถานะห้องอยู่ในหน่วยความจำของ Node.js

> การใช้ GPS บนมือถือผ่านเว็บต้องเป็น HTTPS และเบราว์เซอร์อาจหยุดติดตามเมื่อดับหน้าจอ
